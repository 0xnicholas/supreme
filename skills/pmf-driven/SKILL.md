# PMF-Driven: Find Product-Market Fit Like an Engineer

## Overview

**Product-Market Fit (PMF)** = being in a good market with a product that can satisfy it. — Marc Andreessen

Every startup has two phases: **BPMF** (learn & iterate, PMF score is #1 metric) and **APMF** (scale & execute, growth is #1 metric). Most die BPMF.

**Rachleff's Law:** Great team + lousy market → fail. Lousy team + great market → succeed. **Market matters most.**

---

## Measure PMF

### Sean Ellis Test
Ask active users (≥2 uses in 2 weeks):
> *"How would you feel if you could no longer use [product]?"*
> A) Very disappointed  B) Somewhat disappointed  C) Not disappointed

| "Very disappointed" | Verdict |
|---|---|
| **≥ 40%** | Strong PMF signal |
| 25-39% | On track |
| **< 25%** | Haven't found it |

### Retention Supergraph
- Keeps dropping → **no PMF**
- **Flattens** → users return organically = PMF emerging

---

## The PMF Engine Cycle

### 1. Find HXC
Find your High-Expectation Customer — the persona dominating the "very disappointed" group. Build everything for them.

### 2. Analyze Feedback
- **Very disappointed** → identify core benefit
- **Somewhat disappointed + benefit resonates** → pay close attention (they're close)
- **Not disappointed / benefit doesn't resonate** → politely disregard

### 3. Roadmap
- **50%** double down on core strengths (or competitors overtake)
- **50%** remove barriers for near-miss users (or PMF score won't move)

### 4. Repeat
Track PMF score weekly/monthly as your only OKR.

> **Measure:** True when [metric] reaches [threshold] by [time].
> **Risk:** If wrong, [consequence] within [timeframe].

## Pivot or Persevere

| Signal | Decision |
|---|---|
| Score rising (even below 40%) | Persevere |
| Stagnant after 3-4 cycles | Pivot (market or solution) |
| Retention keeps dropping | Pivot or kill |
| HXC segment too small | Pivot |

## Danger Signals

| Trap | Antidote |
|---|---|
| Premature scaling | Stay small until ≥ 40% "very disappointed" |
| Fake PMF (paid acquisition masks low retention) | Measure organic retention, not totals |
| Founder bias ("everyone I know loves it") | Survey strangers, not friends |
| Too many pivots | Give each hypothesis enough iterations |

## Quick Reference

| When | Action |
|---|---|
| Before building | Write falsifiable hypothesis |
| Need to measure | Run Sean Ellis survey |
| Score < 40% | Start PMF Engine cycle |
| Score ≥ 40% + retention flat | 🎉 PMF. Scale time. |
