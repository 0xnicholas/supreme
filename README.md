# Skills for Builders

Agent skills for builders, entrepreneurs, and product creators — 帮创业者与 Builder 理清思路、验证想法、制定战略、准备融资的技能集。

不知道当前该用哪个技能？从 **[the-grand-tour](#reference--导航)** 开始——它是整片地形的全景地图（🚧 = 规划中）。

## Reference · 导航

- **[the-grand-tour](skills/the-grand-tour/SKILL.md)** — 商业设计全案：四阶段全景地图 + 工具箱 + 心智模式 + 心气源泉。被调用时执行 **Run the Tour**（三问定位 → 路线卡）。地图上的 🚧 条目是规划中、尚未实装的愿景。

## Business · 商业

### 认知与定位（知道做什么）

- **[start-with-why](skills/start-with-why/SKILL.md)** — Golden Circle (Why → How → What)。**Run the Exercise**：收集 5–10 个故事 → 提炼主题 → 起草 Why 一句话 → 用 Celery Test 拿当下真实决策验证 → 交付使命 + How/What 对齐。
- **[pmf-driven](skills/pmf-driven/SKILL.md)** — PMF 工程化。**Run the Engine**：4 问调查工具（Sean Ellis 40% 门槛 + 样本规则）→ 分桶解读 → 50/50 roadmap → 写下周期假设；pivot / persevere 由数据裁决。
- **[challenge-me](skills/challenge-me/SKILL.md)** — 六透镜压力测试（pre-mortem / 假设 / 竞争 / 经济 / 客户 / 执行）。One-Breath 快检或 Deep Dive；收尾 **Refine** 步把最弱点转成最低成本验证与计划修正。
- **[show-me-the-money](skills/show-me-the-money/SKILL.md)** — 融资路演模拟。**Before You Raise** 四闸自检 → persona 模拟（role-play 细则）→ 5 轴评分卡 + **Objection Answer Sheet** 弹药库，越练越厚。

### 战略与模式（知道在哪竞争）

- **[dark-forest](skills/dark-forest/SKILL.md)** — 四层竞品扫描（可见 / 不可见 / 临近 / 未来）+ 护城河诊断（7 Powers）。**Run the Scan**：逐层扫描 → 捕食者模拟（"给你 $10M 怎么杀这家公司"）→ AI-native 检查 → 交付四层竞品地图。

## Engineering · 工程

- **[payoff](skills/payoff/SKILL.md)** — 解释做完一批 tickets 能得到什么：逐张读 ticket 与相关代码，交付「现在 vs 最后一张关单时」的 delta，每条好处可溯源到对应 ticket。AFK 只读、报喜也报忧。[mattpocock/skills](https://github.com/mattpocock/skills) 工作流扩展。
